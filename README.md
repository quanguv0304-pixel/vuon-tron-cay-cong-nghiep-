
# HỆ THỐNG GIÁM SÁT MÔI TRƯỜNG VƯỜN CÂY IoT

## 1. Giới thiệu đề tài

Xây dựng hệ thống IoT giám sát nhiệt độ, độ ẩm môi trường vườn cây (cà phê, hồ tiêu) sử dụng ESP32 và cảm biến DHT22.

Hệ thống thu thập dữ liệu, xử lý trên ESP32, truyền thông qua MQTT và hiển thị trên giao diện Web. Đồng thời hỗ trợ điều khiển thiết bị từ xa.

## 2. Phần cứng sử dụng

- ESP32 DevKit C V4
- Cảm biến nhiệt độ, độ ẩm DHT22
- LED mô phỏng máy bơm
- LED mô phỏng quạt
- LED mô phỏng máy phun sương
- Điện trở 220Ω

## 3. Công nghệ sử dụng

- Arduino IDE / ESP32
- FreeRTOS
- Wi-Fi
- MQTT
- MQTT Broker
- HTML, CSS, JavaScript
- Wokwi Simulator

## 4. Chức năng hệ thống

- Đo và hiển thị nhiệt độ, độ ẩm.
- Truyền dữ liệu cảm biến qua MQTT.
- Hiển thị dữ liệu trên Web Dashboard.
- Điều khiển máy bơm và quạt thủ công qua Web.
- Điều khiển máy phun sương tự động theo ngưỡng độ ẩm.
